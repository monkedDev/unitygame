# Unity 2D Roguelike

Пошаговый 2D рогалик на Unity (переход с Godot).

## Требования

- **Unity**: 6000.6.0f1
- **Шаблон**: Universal 2D
- **Платформа**: Windows, macOS, Linux

## Текущий статус разработки

✅ **Реализовано:**
- Базовая система сетки (`GridManager`)
  - Конвертация между мировыми координатами и координатами ячеек
  - Метод-заглушка для проверки проходимости ячеек
- Менеджер ходов (`TurnManager`)
  - Система состояний игры (PlayerTurn, EnemyTurn, GameOver)
  - Событие `OnTurnChanged` для уведомления о смене хода
- Контроллер хода игрока (`PlayerTurnController`)
  - Обработка ввода WASD/стрелок
  - Ограничение ввода только во время хода игрока
  - Логирование направлений движения

🚧 **В разработке:**
- Физическое перемещение игрока по сетке
- Система противников и ИИ
- Генерация уровня

## Примечания для разработчиков (переход с Godot)

Все скрипты содержат подробные комментарии на русском языке, объясняющие:
- Аналоги систем Godot в Unity
- Различия в подходах (сигналы vs события C#, _process vs Update)
- Особенности реализации паттернов в Unity

## Управление

- **W / Стрелка вверх** — движение вверх
- **S / Стрелка вниз** — движение вниз
- **A / Стрелка влево** — движение влево
- **D / Стрелка вправо** — движение вправо
